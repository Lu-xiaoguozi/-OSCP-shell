# OSCP+ 终极渗透测试清单 · 中文镜像

这是对 [drgoteee.github.io](https://drgoteee.github.io/) 所展示的 OSCP+ 作业清单的本地镜像与中文翻译。页面为纯静态站点，可完全离线使用，不加载任何远程脚本、字体或统计服务。

## 快速开始

直接双击 `index.html` 即可在浏览器中打开。若浏览器限制本地文件读取，也可在本目录启动一个静态服务器：

```bash
python3 -m http.server 8765
# 然后访问 http://127.0.0.1:8765/
```

## 功能

- 全文搜索：条目、命令、分组和阶段标题都可搜索，按 `/` 快速聚焦。
- 优先级筛选：高 / 中 / 低。
- 状态跟踪：未开始 → 侦察 → 立足点 → 提权 → 已攻陷（点击条目右侧状态按钮循环切换）。
- 进度统计：总体完成度、各阶段进度、各分组进度、高优先剩余数量。
- 全部展开 / 全部折叠。
- 进度导出 / 导入（JSON），以及一键重置。
- 进度与界面偏好保存在浏览器 `localStorage`，刷新或关闭页面都不会丢失。
- 响应式布局，桌面端和移动端均可使用。

## 关于上游截断

上游公开版本的 `index.html` 约 430 KB，但内联脚本在条目 `w198` 之后即停止，剩余约 338 KB 全是空白，`<script>` 标签也没有闭合。因此原站实际上无法正常渲染。仓库 README 声称包含 1,229 条、109 台机器、18 个阶段，但可提取的真实内容只有 3 个阶段 / 13 个分组 / 378 条。

本镜像只翻译和呈现上述 378 条真实可提取内容，**没有凭空补造缺失的阶段或条目**。页面顶部的提示条也说明了这一点，关闭后不会再次显示。
